# Stack 📚

A Kotlin implementation of **Stack** data structure with LIFO (Last-In, First-Out) operations.

> 📚 Built as a learning project following the **Data Structures & Algorithms in Kotlin** book by Kodeco (Ray Wenderlich).

---

## Features

- 📥 **Push** — add elements to the top of the stack
- 📤 **Pop** — remove and return the top element
- 👀 **Peek** — inspect the top element without removing it
- 🔢 **Count** — check the number of elements in the stack
- 🔄 **Challenges** — practical exercises like reversing a list and checking balanced parentheses

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/M0bileDev/Algorithms_and_structures_Stack_Data_Structures.git
   ```

2. Run the project:
   ```bash
   ./gradlew run
   ```

> **Note:** The default branch is `develop`.

## Purpose

This project was developed as a hands-on learning exercise to practice stack fundamentals in Kotlin, covering LIFO operations, backing storage with ArrayList, and common stack-based challenges.
